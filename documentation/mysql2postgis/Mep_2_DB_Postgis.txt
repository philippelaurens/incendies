
DOCKER COMPOSE
--------------

Installation sur une instance EC2 (AWS) ou sur n'importe quelle machine avec docker installé (à adapter à Ubuntu/Debian)

    # Install Docker 
    sudo dnf update -y
    sudo dnf install -y docker
    sudo systemctl enable --now docker
    sudo usermod -aG docker ec2-user

    newgrp docker


    # Docker Compose plugin
    sudo mkdir -p /usr/local/lib/docker/cli-plugins
    sudo curl -SL "https://github.com/docker/compose/releases/latest/download/docker-compose-linux-$(uname -m)" \
      -o /usr/local/lib/docker/cli-plugins/docker-compose
    sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose

  o Buildx is Docker’s current image builder. Compose no longer uses the old docker build path by default. What each piece does:

      dockerd — runs containers
      Compose — reads docker-compose.yml, starts services
      Buildx — builds images from your Dockerfile (app: build: ./app)

    # Install Buildx
    VER=$(curl -sL https://api.github.com/repos/docker/buildx/releases/latest | grep -oP '"tag_name": "\K[^"]+')
    echo "version $VER"

    sudo mkdir -p /usr/local/lib/docker/cli-plugins
    sudo curl -fSL "https://github.com/docker/buildx/releases/download/${VER}/buildx-${VER}.linux-${BX_ARCH}" \
      -o /usr/local/lib/docker/cli-plugins/docker-buildx
    sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-buildx

  o docker-compose.yml

      services:
        db:
          image: postgis/postgis:17-3.5
          container_name: postgis
          environment:
            POSTGRES_USER: ${POSTGRES_USER}
            POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
            POSTGRES_DB: ${POSTGRES_DB}
          ports:
            # accessible uniquement localement
            # - "127.0.0.1:5432:5432"  
            # accessible depuis toutes les interfaces
            - "5432:5432"  
          volumes:
            - postgis_data:/var/lib/postgresql/data
            - ./init:/docker-entrypoint-initdb.d
          networks:
            - gis_net
          healthcheck:
            test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER} -d ${POSTGRES_DB}"]
            interval: 5s
            timeout: 5s
            retries: 10
          restart: unless-stopped
          
        app:
          build: ./streamlit/app
          container_name: streamlit
          environment:
            POSTGRES_HOST: db
            POSTGRES_PORT: 5432
            POSTGRES_USER: ${POSTGRES_USER}
            POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
            POSTGRES_DB: ${POSTGRES_DB}
          ports:
            - "8501:8501"
          depends_on:
            db:
              condition: service_healthy
          networks:
            - gis_net
          restart: unless-stopped    

      volumes:
        postgis_data:

      networks:
        gis_net:
          name: gis_net
          driver: bridge

        # sauvegarder uniquement le schéma incendies (dump)
        docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" --schema=incendies --format=custom --no-owner --no-privileges' > incendies_$(date +%Y%m%d).dump

        # sauvegarder uniquement le schéma incendies (sql)
        docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" --schema=incendies --no-owner --no-privileges' > incendies_$(date +%Y%m%d).sql

    - Import : 

        # Création du schéma s'il n'existe pas
        docker compose exec -T db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "CREATE SCHEMA IF NOT EXISTS incendies"'

        # création avee le dump
        docker compose cp incendies_20260911.dump db:/tmp/incendies.dump
        docker compose exec -T db sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --no-owner --no-privileges' < incendies_20260911.dump

        # création avee le sql
        docker compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < incendies_20260911.sql

    - Folium place des marqueurs sur une carte Leaflet. Un marqueur = une paire lat / lon en degrés, éventuellement un libellé et une couleur liée à valeur. Il ne comprend pas geometry / geography PostGIS. Si vous lui passez geom, il faut d’abord extraire les coordonnées (ST_Y, ST_X) ou du GeoJSON (ST_AsGeoJSON). Les colonnes latitude / longitude évitent cette conversion pour une carte de points.
            
        # app.py
        import os
        import streamlit as st
        import psycopg

        import folium
        from streamlit_folium import st_folium
        from popups import site_popup

        def get_conn():
            return psycopg.connect(
                host=os.environ["POSTGRES_HOST"],
                port=os.environ.get("POSTGRES_PORT", "5432"),
                user=os.environ["POSTGRES_USER"],
                password=os.environ["POSTGRES_PASSWORD"],
                dbname=os.environ["POSTGRES_DB"],
            )

        st.title("Terre, Vent, Feu, Eau, Data")

        with get_conn() as conn:
            with conn.cursor() as cur:
                cur.execute(
                    """
                    SELECT nom, latitude, longitude, valeur
                    FROM lieux
                    """
                )
                rows = cur.fetchall()

        if rows:
            lats = [lat for _, lat, lon, _ in rows]
            lons = [lon for _, lat, lon, _ in rows]
            m = folium.Map(
                location=[sum(lats) / len(lats), sum(lons) / len(lons)],
                zoom_start=6,
            )
        else:
            m = folium.Map(location=[46.7, 2.5], zoom_start=6)

        for nom, lat, lon, valeur in rows:
            # folium.Marker(
            #     location=[lat, lon],
            #     popup=f"{nom} : {valeur}",
            #     tooltip=nom,
            # ).add_to(m)
            folium.CircleMarker(
                location=[lat, lon],
                radius=max(3, min(8, float(valeur) / 3)),
                color="#c1121f",
                fill=True,
                fill_color="#c1121f",
                fill_opacity=0.8,
                # popup=f"{nom} : {valeur}",
                popup=site_popup(nom, valeur, unite="mm"),
                tooltip=nom,
            ).add_to(m)

        st_folium(m, width=800, height=600)
